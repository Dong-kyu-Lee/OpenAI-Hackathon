## 1. 확정된 방향

- [x] 플레이어는 화면상 고정된 위치를 유지한다.
- [x] 맵 세그먼트와 그 자식 오브젝트가 플레이어 뒤쪽으로 이동한다.
- [x] 화면 뒤로 벗어난 세그먼트는 제거하거나 풀에 반환한다.
- [x] 앞쪽에는 항상 필요한 길이만큼 세그먼트를 준비한다.
- [x] 게임플레이 장애물은 완전 무작위가 아닌 검증된 패턴을 조합한다.
- [x] 난이도는 진행 거리와 맵 이동 속도를 기준으로 상승시킨다.
- [x] 플레이어 구현과 맵 구현은 데이터 및 이벤트 인터페이스로 분리한다.

## 2. 목표 구조

```text
DifficultyDirector
        |
        v
MapScrollController ---> MapStreamManager ---> MapSegmentPool
                                |
                                v
                       ObstaclePatternGenerator
                                |
                                v
                       Obstacle / Pickup Pools
```

### 주요 책임

| 구성 요소 | 책임 |
|---|---|
| `MapScrollController` | 맵 이동 속도, 시작, 정지, 일시정지 관리 |
| `MapSegment` | 세그먼트 길이, 시작·종료점, 배치 루트 관리 |
| `MapStreamManager` | 세그먼트 생성, 연결, 활성 목록, 반환 관리 |
| `MapSegmentPool` | 세그먼트 프리팹 재사용 |
| `ObstaclePattern` | 검증된 장애물 조합 데이터 |
| `ObstaclePatternGenerator` | 난이도에 맞는 패턴 선택과 연결 |
| `PatternValidator` | 생성된 패턴의 통과 가능성 검사 |
| `DifficultyDirector` | 진행도에 따른 속도와 패턴 난이도 계산 |
| `PlayerTraversalProfile` | 맵 생성에 필요한 플레이어 이동 능력 데이터 |

## MAP-003. MapScrollController 구현

- 상태: 진행 중
- 담당자: 김유경
- 선행 작업: MAP-002

### 구현 체크리스트

- [x] 초기 이동 속도를 설정할 수 있다.
- [x] 현재 이동 속도를 조회하고 변경할 수 있다.
- [x] 시작·정지·일시정지·재개를 지원한다.
- [ ] 활성 세그먼트에 동일한 이동량을 적용한다.
- [x] `Time.timeScale` 의존 여부를 명확히 한다.
- [x] 이동 콜라이더가 있다면 물리 업데이트 주기에 맞춰 이동한다.
- [ ] 게임 재시작 시 속도와 누적 거리를 초기화한다.

### 완료 조건

- [x] 고정된 테스트 캐릭터 앞에서 바닥이 일정한 속도로 흐른다.
- [ ] 일시정지와 재개 시 위치 튐이 없다.

### 메모

- `MapScrollSettingsSO`의 초기 속도를 사용하며 런타임 속도는 음수 입력을 절댓값으로 정규화한다.
- `MapScrollController`는 속도·누적 거리·실행·일시정지 상태를 읽기 전용으로 제공한다.
- 이동은 `FixedUpdate`와 `Time.fixedDeltaTime`을 사용하므로 scaled time 기반이며, `Time.timeScale`이 0이면 물리 업데이트도 멈춘다.
- 등록된 모든 `IMapScrollTarget`에 같은 월드 `-X` displacement를 전달하고, 적용 중 등록·해제 요청은 반복 종료 후 반영한다.
- `MapRuntime.prefab`을 별도 미저장 additive 테스트 씬에서 실행해 고정 Probe 앞에서 `Rigidbody2D.MovePosition` 기반 바닥 이동과 Probe 위치 고정을 확인했다.
- 기존 활성 세그먼트는 함께 이동했지만 런타임에 새로 연결된 세그먼트는 이전 세그먼트와 `0.16` 유닛 간격이 생겼다. 같은 물리 프레임의 스크롤 적용 시점 차이가 의심되므로 활성 세그먼트 동일 이동량 항목은 미완료로 유지한다.
- `ResetForRestart`는 초기 속도와 누적 거리를 초기화하지만 App/GameManager 재시작 이벤트 규격이 미확정이라 통합 항목은 완료 처리하지 않았다.
- 일시정지·재개 검증은 연결부 smoke 실패 후 중단해 완료 조건을 체크하지 않았다.

## MAP-004. MapSegment 구현

- 상태: 진행 중
- 담당자: 김유경
- 선행 작업: MAP-002

### 구현 체크리스트

- [x] 세그먼트 길이 또는 종료 앵커를 제공한다.
- [x] `Activate` 또는 동등한 초기화 메서드를 제공한다.
- [x] `Deactivate` 또는 동등한 정리 메서드를 제공한다.
- [ ] 자식 장애물·아이템·장식을 정리할 수 있다.
- [x] 재사용 시 이전 실행의 상태가 남지 않는다.
- [x] 세그먼트 종류 ID 또는 프리팹 키를 제공한다.

### 완료 조건

- [x] 하나의 세그먼트를 여러 번 활성화·비활성화해도 동일한 초기 상태가 된다.

### 메모

- `MapSegment`는 세그먼트 ID, Entry/Exit 앵커와 콘텐츠 Root를 읽기 전용으로 제공한다.
- 길이는 Entry/Exit 앵커의 로컬 X 차이로 계산하고, 앵커가 없거나 Exit가 Entry보다 앞서지 않으면 0을 반환한다.
- `OnEnable`, `Activate`, `Deactivate`에서 Rigidbody2D 속도와 자체 활성 상태를 초기화한다.
- 활성 세그먼트의 이동은 `IMapScrollTarget.ApplyScroll`에서 `Rigidbody2D.MovePosition`으로 처리한다.
- GameObject 활성 전환과 스크롤 등록·해제는 각각 MAP-007 풀과 MAP-006 스트림 관리자의 책임으로 남긴다.
- 장애물·아이템·장식 풀 구현이 없으므로 자식 콘텐츠 정리 항목은 아직 완료하지 않았다.
- Play Mode에서 초기 총 9개 인스턴스만으로 200 유닛 이상 스트리밍하며 반환·재대여가 반복됐고, 종료 후 `9 total = 0 active + 9 inactive`로 복구되어 물리 활성 상태가 누적되지 않음을 확인했다.

## M1. 장애물 없는 무한 스크롤 통합 검증

- [x] 플레이어는 화면상 고정되어 있다.
- [x] 맵만 뒤쪽으로 이동한다.
- [ ] 맵 생성과 제거가 화면 밖에서 이루어진다.
- [ ] 세그먼트 연결부가 보이지 않는다.
- [ ] 일시정지·재개·재시작이 정상 동작한다.
- [ ] 10분 연속 실행 중 활성 세그먼트 수가 일정 범위를 유지한다.

### 검증 메모

- 저장하지 않는 additive 테스트 씬에서 `MapRuntime.prefab`과 고정 `PlayerProbe`를 실행했다. Probe는 월드 `(0, 1)`에 고정됐고 맵만 월드 `-X`로 이동했다.

- 반환·재생성 후 모든 연속 연결부에서 정확히 `0.16` 유닛의 간격이 재현되어 smoke가 실패했다. 계획에 따라 일시정지·재개·재시작 후속 검증, 10분 실행과 Profiler GC 검증은 수행하지 않았다.
- Unity Console Error는 0건이었고, 테스트 종료 후 임시 씬은 저장하지 않고 닫았다. 기존 `MapTest.unity`는 루트 `Main Camera`, `StageRuntime`과 `dirty=false` 상태를 유지했다.

## 5. 구현 원칙

### 장애물 생성 원칙

- 개별 장애물을 완전 무작위로 생성하지 않는다.
- 사람이 검증한 `ObstaclePattern`을 데이터로 제작한다.
- 생성기는 난이도·가중치·연결 조건에 따라 패턴을 조합한다.
- 검사에 실패한 패턴은 배치하지 않는다.
- 배치 가능한 패턴이 없으면 항상 안전 패턴으로 대체한다.

### 플레이어 코드와의 경계

- 맵은 플레이어의 이동·체력·애니메이션을 직접 제어하지 않는다.
- 플레이어는 자신의 행동 능력을 데이터나 인터페이스로 제공한다.
- 맵은 해당 데이터를 이용해 간격과 통과 가능성만 계산한다.
- 장애물 충돌 결과는 이벤트 또는 플레이어 측 인터페이스로 전달한다.

### 성능 원칙

- 세그먼트·장애물·아이템은 반복 생성·삭제하지 않고 풀로 재사용한다.
- 화면 밖 콘텐츠만 생성·초기화·반환한다.
- 모든 자식 오브젝트를 개별 이동하기보다 세그먼트 루트를 이동한다.
- 디버그 기능은 릴리스 빌드에서 비활성화할 수 있게 한다.
